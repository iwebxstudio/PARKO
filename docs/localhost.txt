PARKO — ข้อมูลพอร์ตและการเข้าใช้งาน (อัปเดตพอร์ตใหม่)
===================================================

[วิธีที่ 1] รันผ่าน Docker ทั้งระบบ (แนะนำ):
- หน้าเว็บหลัก (HTTP):  http://localhost:39741
- หน้าเว็บ SSL (HTTPS): https://localhost:39742
- Backend API (ตรง):   http://localhost:39743/api
- PostgreSQL (Host):   localhost:39744
- Redis (Host):        localhost:39745

* บัญชีเข้าสู่ระบบ:
  - Admin: admin / admin123 (หรือ admin1234)
  - Staff: staff01 / staff123 (หรือ staff1234)
  (สามารถกดคลิกที่การ์ด Demo Credentials ในหน้า Login เพื่อเติมรหัสผ่านอัตโนมัติได้)

---------------------------------------------------
[วิธีที่ 2] รันแบบ Manual / Development:
1. เปิด Backend (API):
   cd d:\PARKO\backend
   npm run start:dev

2. เปิด Frontend (หน้าเว็บ):
   cd d:\PARKO\frontend
   npm run dev
   URL: http://localhost:5173/

หรือดับเบิลคลิกไฟล์ .\dev.bat เพื่อเปิดทำงานพร้อมกัน
