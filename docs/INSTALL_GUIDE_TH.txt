=======================================================
คู่มือการติดตั้งและย้ายโปรเจกต์ PARKO ไปยังเครื่องใหม่ (อัปเดตล่าสุด)
=======================================================

ระบบได้รับการปรับปรุงให้รองรับการย้ายเครื่องและเปิดใช้งานได้อย่างรวดเร็ว
โดยการรันโปรเจกต์มี 2 วิธีหลักๆ ดังนี้ (แนะนำวิธีที่ 1 สำหรับการย้ายเครื่องทั่วไป):

-------------------------------------------------------
วิธีที่ 1: การรันผ่าน Docker ทั้งระบบ (ง่ายที่สุด - แนะนำสำหรับการย้ายเครื่อง)
-------------------------------------------------------
วิธีนี้เครื่องปลายทางจำเป็นต้องมีเพียงโปรแกรมเดียวคือ:
- Docker Desktop (ดาวน์โหลดได้ที่: https://www.docker.com/products/docker-desktop/)

ขั้นตอนการรันระบบ:
1. คัดลอกโฟลเดอร์โปรเจกต์ PARKO ไปยังเครื่องใหม่ (ตรวจสอบว่ามีไฟล์ `parko_db_backup.sql` อยู่ในโฟลเดอร์ด้วย)
2. เปิด Command Prompt (CMD) หรือ PowerShell ในโฟลเดอร์โปรเจกต์ เช่น:
   cd D:\PARKO
3. รันคำสั่งเปิดใช้งานระบบทั้งหมด:
   docker-compose up -d
4. รอระบบดาวน์โหลดและติดตั้งประมาณ 2-3 นาที ระบบจะเตรียมการให้คุณโดยอัตโนมัติ:
   - ฐานข้อมูลจะถูกเปิดใช้งานและดึงข้อมูลเดิมจาก `parko_db_backup.sql` เข้าไปโดยอัตโนมัติ (ไม่ต้องรันคำสั่งนำเข้าฐานข้อมูลเอง)
   - หน้าเว็บ Frontend และระบบ Backend รวมถึง Nginx Gateway จะเริ่มทำงานโดยพร้อมเพรียงกัน
5. เปิดเบราว์เซอร์และเข้าใช้งานที่:
   http://localhost:39741
   (สามารถปรับแต่งค่าพอร์ต `PARKO_PORT` ในไฟล์ `.env` ได้)

* ข้อมูลผู้ดูแลระบบเริ่มต้นสำหรับเข้าใช้งาน:
  Username: admin
  Password: admin123

-------------------------------------------------------
วิธีที่ 2: การรันแบบพัฒนา (Hybrid - ฐานข้อมูลใน Docker + แก้ไขโค้ดภายนอก)
-------------------------------------------------------
เหมาะสำหรับนักพัฒนาที่ต้องการแก้ไขโค้ดและเห็นผลลัพธ์ทันที (Hot Reload):

ความต้องการเพิ่มเติม: Node.js เวอร์ชัน 18 ขึ้นไป

ขั้นตอนการใช้งาน:
1. ทำการเปิดเฉพาะ PostgreSQL และ Redis บน Docker:
   docker-compose up -d postgres redis
2. นำเข้าข้อมูลเดิม (Restore Database):
   - หากใช้ PowerShell:
     cmd.exe /c "type parko_db_backup.sql | docker exec -i parko-postgres psql -U parko -d parko_db"
   - หากใช้ Command Prompt (CMD):
     type parko_db_backup.sql | docker exec -i parko-postgres psql -U parko -d parko_db
3. เปิดหน้าต่าง Terminal ใหม่ สำหรับ Backend:
   cd D:\PARKO\backend
   npm install        (ทำเฉพาะครั้งแรกครั้งเดียว)
   npm run start:dev
4. เปิดหน้าต่าง Terminal ใหม่ สำหรับ Frontend:
   cd D:\PARKO\frontend
   npm install        (ทำเฉพาะครั้งแรกครั้งเดียว)
   npm run dev
5. เปิดเบราว์เซอร์และเข้าใช้งานที่:
   http://localhost:5173

-------------------------------------------------------
การแก้ไขปัญหาพอร์ตชนกัน (Port Conflict)
-------------------------------------------------------
หากขึ้นข้อผิดพลาดเกี่ยวกับพอร์ตถูกเปิดใช้งานอยู่ (เช่น Port 8080 หรือ 3000 ชนกับโปรเจกต์อื่น):
- ให้เปิดไฟล์ `.env` ในโฟลเดอร์โปรเจกต์ PARKO
- แก้ไขพอร์ตในส่วนด้านล่างนี้ตามต้องการ:
  * PARKO_PORT=39741        (พอร์ตเข้าหน้าเว็บหลัก HTTP)
  * PARKO_SSL_PORT=39742    (พอร์ตเข้าหน้าเว็บ HTTPS)
  * BACKEND_HOST_PORT=39743 (พอร์ตเซิร์ฟเวอร์ Backend บนเครื่อง Host)
  * POSTGRES_HOST_PORT=39744 (พอร์ตฐานข้อมูลบนเครื่อง Host)
  * REDIS_HOST_PORT=39745   (พอร์ต Redis บนเครื่อง Host)
